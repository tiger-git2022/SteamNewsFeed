# SteamNewsFeed（Steam 新闻聚合）

一个 Windows 小工具：把 [Steam 新闻中心](https://store.steampowered.com/news/) 的新闻流，和**你关注的发行商 / 开发商新发售的游戏**合成一条时间线。

Steam 新闻中心只显示发行商自己发了新闻的内容。很多发行商出了新游戏，只在游戏自己的页面上发公告，甚至什么都不发，
关注了也看不到。这个程序会定时检查每个关注的发行商最近出的游戏，把新闻流里漏掉的补上：

- 新闻流里已经有这款游戏的发售新闻 → 不重复，在那条新闻上标「新发售」并附上游戏卡片；
- 新闻流里没有、但游戏自己的页面上有 → 把游戏页上的发售新闻推过来；
- 都没有 → 按 Steam 发售通知的样子生成一张「《游戏名》 – 现已正式发售！」：封面大图、发售通知、游戏链接卡片（简介、标签、发售日、价格）和简介。

其他功能：

- **和新闻中心一样的筛选**：Steam「精选」的热门游戏（不在你的库、愿望单、关注里）默认不显示，和 Steam 新闻中心的默认设置一样，设置里可以打开。
- **去重**：多个账号发的同一篇新闻（标题、正文都一样）只显示一条，并注明「另有 XX 也发了」。
- **屏蔽**：每条右上角的「⋯」可以屏蔽这个游戏或账号，之后它的新闻和新发售都不再显示、也不弹通知；在设置里可以取消。
- **阅读进度**：比上次读到的地方新的内容标「新」，往下滚把它滚出屏幕顶部才记为看过（还在屏幕上的「新」一直留着）。「上次看到这里」分界线在离开（退出、最小化、缩到托盘）时记下位置，回来后一直停在那里；手动刷新后先隐藏，下次离开再记。还有「跳到上次看到的位置」「全部标为已读」，下次打开回到上次看到的位置。右下角的圆按钮在顶部时是「刷新」，往下滚了是「回到顶部」（同时全部记为已读）。左侧和托盘图标上显示未读数。
- **展开全文、评论**：点文章本身就能在程序里展开全文；有评论的新闻直接显示最新几条评论，可以继续往下看。
- **跳转浏览器、加入愿望单**：右上角的 Steam 图标在浏览器中打开；有游戏的条目可以直接加入 / 移出愿望单。
- **翻译（大模型）**：接 OpenAI 兼容接口（DeepSeek、通义千问、Kimi、智谱、硅基流动、OpenRouter 等）或 Anthropic Claude，翻译新闻和评论。可以手动点「译」，也可以对非中文内容自动翻译；可选思考 / 不思考 / 超过一定字数才思考，流式（边翻边显示）或一次显示。翻译过的会缓存，不重复花额度。
- **评测**：游戏卡片上显示评价等级、好评率和好评数 / 总评测数（已发售的游戏）。
- **价格**：按你账号的商店地区显示（比如卢布），后面按当天汇率换算成人民币（可以关）。
- **DLC**：关注的发行商出的 DLC 也推送（可以关）。
- **后台刷新**：定时自动刷新（默认每 30 分钟）；点关闭缩到托盘，发现新发售的游戏弹通知；可以开机自动启动（直接缩在托盘）。
- **亚克力半透明窗口**，浅色 / 深色主题，托盘右键菜单，和 [WE 加权轮播](https://github.com/tiger-git2022/WallpaperEngineRandom)、[N网 Mod 更新](https://github.com/tiger-git2022/NexusModUpdater) 同一套界面风格。

## 下载

到 [Releases](../../releases) 下载最新的 `SteamNewsFeed.exe`（只有这一个文件，不用解压），放到一个固定文件夹
（例如 `C:\Tools\SteamNewsFeed\`），双击打开即可。

- 系统要求：Windows 10 / 11（64 位），自带的 .NET Framework 4.8 和 Edge WebView2，不需要另外安装运行库。
- **更新**：有新版本时窗口左下角会出现提示，点一下就能自动下载新的 exe 并替换，设置和阅读进度不动，完成后自动重新打开；
  也可以在「设置 → 关于」里手动检查。

程序运行时生成的文件（设置、阅读进度、日志、Steam 登录状态）都放在 exe 所在的文件夹里，删掉文件夹就彻底卸载。

## 第一次使用

1. 打开程序，点「登录 Steam」。登录在 Steam 官方的登录页里完成（账号密码、手机令牌、扫码都行），账号密码不经过这个程序。
   登录状态保存在程序文件夹的 `webview2` 里，大约一天过期一次，程序会自动续期。
2. 等第一次刷新完成（要读新闻流，还要检查每个关注的发行商最近出的游戏，比之后慢一些）。
   第一次运行时，最近 30 天（可以改）里关注的发行商发售的游戏都会补进时间线。
3. 想推送哪些发行商的新游戏，就在 Steam 上关注它（发行商 / 开发商的商店页右上角「关注」）。
4. （可选）要翻译的话，到「设置 → 翻译（大模型）」选接口格式，填接口地址、API 密钥和模型，点「测试」看能不能用。
   密钥用 Windows 的 DPAPI 加密后存在设置文件里，只有当前 Windows 用户能解开。

## 翻译怎么开「思考」

不同服务商开关思考的方式不一样，程序按接口地址自动选：

| 服务商 | 怎么开关思考 |
|---|---|
| 通义千问（dashscope）、硅基流动、ModelScope | `enable_thinking` |
| 智谱（bigmodel / z.ai）、火山方舟 | `thinking.type` |
| OpenRouter | `reasoning.enabled` |
| OpenAI（o 系列、gpt-5） | `reasoning_effort` |
| DeepSeek、Kimi 等靠换模型的 | 在「思考时换用的模型」里填，比如 `deepseek-reasoner` |
| Anthropic Claude | 思考：自适应思考；不思考：effort 调到最低（新的 Claude 模型思考关不掉） |

「超过一定字数才思考」按词数算（中日韩的字一个算一个词），默认 800。

## 怎么判断「新发售」

- 每次刷新，读每个关注对象商店页上按「最新发行」排的前几个游戏；
- 用 Steam 的商店接口查这些游戏的发售时间和发行商 / 开发商：**已经正式发售**（「即将推出」的不算）、
  **发行商或开发商是你关注的那个**（关注的鉴赏家推荐的别家游戏默认不算，设置里可以打开），就算一个新发售；
- 找发售新闻：发售前 3 天到发售后 14 天之内，标题提到这个游戏、带「发售 / 上线 / 推出 / Released / Out now」之类字样的新闻
  （「试玩版」「愿望单」「更新」之类的不算）。发售 3 天后还没有发售新闻，就一直用生成的卡片。

## 文件说明

| 文件 | 用途 |
|---|---|
| `snf.config.json` | 全部设置（包括屏蔽列表、加密后的 API 密钥） |
| `snf.state.json` | 阅读进度、上次的位置、发现过的游戏和发售、汇率、翻译缓存 |
| `snf.log` | 日志，出问题先看这里（设置 → 查看日志） |
| `webview2/` | 内嵌浏览器的数据（Steam 登录状态，不要发给别人）；`webview2/loader/` 里是程序启动时释放出来的 WebView2Loader.dll |

## 常见问题

- **一直「正在刷新」或者提示连不上 Steam**：程序走系统代理，和浏览器一样；浏览器能打开 Steam 商店，程序就能用。
- **提示登录过期**：到「设置 → 账号」点「重新登录」。
- **某个发行商的新游戏没出现**：确认在 Steam 上关注的是它的发行商 / 开发商页面；游戏要已经正式发售，并且发行商或开发商写的就是这个页面。
- **价格不是卢布 / 人民币**：价格跟着你 Steam 账号的商店地区走，汇率每半天更新一次（open.er-api.com，备用 fawazahmed0/currency-api）。
- **Steam 新闻中心里有、程序里没有（或者反过来）**：先看是不是被屏蔽了（设置 → 新闻流），再看「显示 Steam 精选」开没开。新闻中心左边的筛选只存在你浏览器里，程序读不到，程序按 Steam 的默认筛选来。
- **翻译失败**：在「设置 → 翻译」点「测试」，会显示服务商返回的错误（密钥不对、余额不足、模型名写错等）。

## 从源码编译

源码在 `windows/`（C#，.NET Framework 4.8，界面使用 [WPF-UI](https://github.com/lepoco/wpfui) + WebView2）。

```powershell
dotnet build windows\SteamNewsFeed.csproj -c Release -o out --no-incremental
```

## 发布流程

改动都在新分支上做，开 PR 到 `main`：PR 上 GitHub Actions 会先编译一遍，编译通过再合并。
要发新版本时，在 [CHANGELOG.md](CHANGELOG.md) 顶部加一节 `## [X.Y.Z] - 日期`，随 PR 合并到 `main`。GitHub Actions 发现这个版本号还没有 `vX.Y.Z` 标签，就会自动编译，把编译好的单个 `SteamNewsFeed.exe`（依赖都用 Costura 打包在里面）发布到 Releases 并打上标签。最上面一节写成 `- 未发布` 时只编译、不发布。

也可以自己推送形如 `vX.Y.Z` 的 tag 来发布。

更新记录见 [CHANGELOG.md](CHANGELOG.md)。
